#### RefStat
[refstat.se](https://refstat.se/)

A statistics platform for Swedish football and floorball referees. It pulls match data from FOGIS and IBIS, two federation systems with different structures, and combines them into one view. Live with active referees, built and run on my own on Cloudflare Workers.

#### Copa Solar, March–June 2026
[copa-solar.github.io](https://copa-solar.github.io)

A platform for energy calculations on solar façades. I worked on the serverless AWS backend, defined as code in a TypeScript CDK app, brought six external data sources into one data model, and set up CI/CD in GitHub Actions with around 100 automated tests.
